## 👋 About Me

I'm a full-stack and AI developer who builds production-ready web applications end to end — from database schema and API design through to polished, responsive interfaces. I care about writing code that's easy to read six months later, not just code that works today.

My approach is practical over trendy: pick the right tool for the problem, keep architecture simple until complexity is actually needed, and ship things real users can rely on.

- 🔭 **Currently building** — AI-powered applications and full-stack products, end to end
- 🧩 **Comfortable across the stack** — from relational schema design to pixel-level UI polish
- 🤖 **Focus area** — integrating AI/LLM capabilities into practical, everyday tools
- 🌱 **Always learning** — new frameworks, better architecture patterns, and cleaner ways to ship
- 💬 **Ask me about** — React/Next.js architecture, API design, or turning an idea into a working MVP
